Decisions fixed for executors
-----------------------------
- Use a dedicated preview hostname by default, separate from Mobile's exact
  public origin. Operator supplies DNS; Caddy supplies TLS. Multiple Live
  sessions use separate preview ports on that dedicated hostname initially,
  bounded by an operator-configured port range. Same hostname as Mobile on
  another port is unsupported initially: cookies are not port-scoped. The
  auth milestone must verify Mobile cookies are host-only; if not, correct
  their scope without invalidating passkeys. Preview cookies must also carry
  a server-checked Live/port audience. Strip unrelated cookies before proxying
  to application servers. Never send Mobile credentials to project content.
- Configure a small bounded pool of preview ports, with explicit firewall instructions; do not bind an unbounded port range. Persist an origin-to-canonical-app assignment and do not recycle that origin for another app: service workers and browser storage can outlive Stop. Multiple apps must never share an origin. Report pool exhaustion explicitly; a future per-app-hostname design may expand capacity. Keep the dev app at / on its preview origin. Reserve /__gestalt_live/ for
  helper and authorization endpoints; reject apps that collide with it.
  Inject an explicit HTTPS public helper base URL; browser code must not call
  localhost. Same-origin helper routing avoids third-party cookie reliance.
- Preview authorization uses a short-lived, single-use launch grant obtained
  through authenticated Mobile. Exchange it at the preview origin for a
  Secure, HttpOnly, host-only cookie scoped to that Live instance and port.
  Prefer a URL fragment followed by POST exchange; never put bearer grants
  in query strings, logs, analytics or Referrer. Exchange page has no external
  assets and uses no-store + no-referrer. Grant replay/wrong origin/expiry
  fails closed. Every proxied request, including assets, SSE and WebSocket
  handshake, checks the current authorization and instance state.
- Revoke preview access on Stop, logout/device revocation, expiry and owner
  loss. Bound open SSE/WebSocket lifetimes and actively close owned streams
  on revocation; handshake-only checks are insufficient. Do not add passkey
  export, recovery or a second hosted auth database administration surface.
- Put the Caddy admin endpoint on a restricted Unix socket. Browser code,
  project processes and ordinary agent tools must not reach it. A socket mode
  alone is insufficient if the controller and agent share a UID: integrate
  the existing managed permission boundary or a narrowly authorized broker,

  proved, fail capability readiness; do not claim that localhost is safe.

  the local API, with conflict detection and reconciliation after reload.
- Canonical Impeccable state remains .impeccable/live under its supported app
  root initially. IMPECCABLE_LIVE_CONFIG only overrides config, not all state.
  Gestalt controller metadata belongs below workspace .gestalt/live; secrets
  belong in private controller state, outside project-readable files.
