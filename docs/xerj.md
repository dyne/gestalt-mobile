# Retired Xerj integration

Mobile no longer installs, launches, indexes, connects to or displays Xerj.
Native text search, Serena, context-mode, managed browser tools and session
history remain available through their existing contracts.

Remove obsolete `--xerj` arguments from manual invocations. For an older
managed installation, run `gestalt update` before reopening a session. The
manager migrates positively identified generated configuration and recognized
stored restart arguments. Mobile detects old managed MCP entries by the selected
manager's canonical executable and complete generated arguments, including
aliases, and reports update guidance before starting the retired service.
Names alone never establish ownership. Unresolved executables, custom arguments
and user-defined transports remain unchanged and may need operator review.

Compatibility handling removes only complete flat owned legacy instruction
blocks from Mobile's in-memory override. It ignores old extra payload fields
and retired telemetry without rewriting user profiles, databases or thread
history. No disabled backend or no-op feature switch remains.

Installed binaries, indexes, repositories, sessions, authentication, passkeys and
skill-profile data are preserved. Retirement does not grant Mobile authority to
stop an independently owned service or delete legacy data.
